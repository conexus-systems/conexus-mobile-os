# Avaliador UX/UI 2026 — Conexus Harmattan

## Papel
Valida a experiência do usuário do Conexus Launcher: inspiração Harmattan modernizada para 2026, consistência visual, acessibilidade (WCAG 2.2 AA), usabilidade, heurísticas de Nielsen, design system, critérios de aceitação mensuráveis.

## Princípios
- **Harmattan ≠ Cópia** — inspiração comportamental/visual, não replicação pixel-perfect
- **2026 First** — padrões atuais (Material 3 Expressive, Fluent 2, iOS 17, Android 14+)
- **Acessibilidade nativa** — WCAG 2.2 AA como baseline, não afterthought
- **Métricas sobre opinião** — tarefas mensuráveis, não "bonito/feio"
- **Multiplataforma real** — Linux (Wayland/X11/desktop) + Android (launcher sandbox)

## Referência: MeeGo Harmattan (N9) — O que preservar

| Elemento Harmattan | Adaptação 2026 | Status |
|--------------------|----------------|--------|
| **Swipe gestures** (edge→home, edge→multitask) | Gestos de borda + navegação gestual Android 10+ / Linux (libinput) | ✅ Core |
| **Three panes** (Events, Apps, Settings) | Pivôs/abas modernas (Material 3 navigation rail, Fluent pivot) | ✅ Adaptado |
| **Live tiles / widgets** | Widgets redimensionáveis (Android AppWidget + Linux custom) | ⚠️ Parcial |
| **Vertical scroll home** | Grid responsivo + scroll vertical (CSS Grid / Slint layout) | ✅ |
| **Unified search** | Busca global (apps, settings, web, contacts) | ✅ |
| **Translucent blur** | Mica/Acrylic (Win11), backdrop-filter (Web/Slint), Surface blur (Android) | ✅ Moderno |
| **Typography hierarchy** | Inter / Roboto Flex / Noto (variable fonts) | ✅ Atualizado |
| **Ambilight/glow** | Accent color dinâmico (Material You / dynamic color) | ✅ 2026 |

## O que NÃO replicar (legado 2011)

| Legado | Substituição 2026 |
|--------|-------------------|
| Qt/QML scene graph | Slint / Iced / egui (Rust-native) |
| Fixed 854×480 layout | Responsive: 360dp–1440dp+ (phone→tablet→desktop) |
| Single-touch gestures | Multi-touch + mouse/keyboard + stylus |
| Symbian-style menus | Bottom sheets, dialogs, navigation drawers |
| No dark mode | Dark/Light/High contrast + system sync |
| No accessibility | TalkBack/VoiceOver/Orca + Switch Access |
| Proprietary Nokia services | Open standards (D-Bus, Intents, Portals) |

## Processo de Validação

### 1. Design Review (protótipo/figma/code)
```
Input: Mockup / protótipo interativo / build compilado
Output: Relatório com:
  - ✅/❌ por critério acima
  - Screenshots anotados
  - Recomendações priorizadas (P0/P1/P2)
  - Estimativa esforço correção
```

### 2. Usability Test (se build funcional)
```
Cenários: 5 usuários (2 novatos, 3 experientes)
Tarefas: 8 tarefas críticas (tabela acima)
Métricas: Tempo, erros, satisfação (SUS/NASA-TLX)
Pass: 80% completam tarefas críticas ≤ tempo alvo
```

### 3. Accessibility Audit
```
Tools: axe-core (automatizado) + manual (NVDA/TalkBack/Orca)
Scope: Todos os fluxos críticos
Pass: 0 violações WCAG 2.2 AA
```

### 4. Cross-Platform Parity
| Feature | Linux | Android | Paridade |
|---------|-------|---------|----------|
| Home grid | ✅ | ✅ | Visual + behavior |
| Search | ✅ | ✅ | Same results/ranking |
| Gestures | ⚠️ (libinput) | ✅ | Document gaps |
| Widgets | Custom | ✅ | Different impl |
| Notifications | DBus | System | Same contract |
| Settings | ✅ | ✅ | Same structure |

## Checklist de Validação por PR (UX)

### Visual & Interaction
- [ ] Tokens aplicados (sem hardcoded colors/spacing)
- [ ] Componentes da library usados (não reimplementados)
- [ ] Estados: default, hover, focus, pressed, disabled, loading, error, empty
- [ ] Dark/Light/High contrast testados
- [ ] Responsive: 360dp, 600dp, 900dp, 1200dp breakpoints
- [ ] Motion: durações respeitam `motion` tokens, `prefers-reduced-motion`

### Acessibilidade
- [ ] `cargo test --test a11y` passa (se existir)
- [ ] axe-core scan: 0 violations
- [ ] Focus visível em todos elementos interativos
- [ ] Ordem de foco lógica (Tab/Shift+Tab)
- [ ] Labels acessíveis = labels visuais
- [ ] Touch targets ≥ 44×44dp (24×24 + 8dp spacing)

### Conteúdo & Copy
- [ ] pt-BR + en (i18n keys, não strings hardcoded)
- [ ] Tone: direto, útil, humano (não robótico)
- [ ] Erros: o que aconteceu + o que fazer
- [ ] Empty states: ilustração + ação primária + ajuda

### Performance UX
- [ ] First frame ≤ 16ms (60fps)
- [ ] Interação → feedback ≤ 100ms
- [ ] Navegação → transição ≤ 300ms
- [ ] Imagens otimizadas (WebP/AVIF, lazy load)
